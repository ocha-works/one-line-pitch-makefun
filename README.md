A one-sentence pitch that convinces a friend who has never coded to let an AI agent build their first app idea on make.fun — free to try, no code to write, the agent does the building.

## Run it

```sh
node main.ts
```

Node 22.18 or later, standard library only, no build step and no network. Running it writes the pitch (189 characters, one sentence) to `/output/entry.txt`. Running it twice writes the same bytes.
